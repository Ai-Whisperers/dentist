## RECOMMENDED STRUCTURE

### Section 1: Before Your Appointment

```
+---------------------------------------------------+
|  HOW TO PREPARE FOR YOUR FIRST VISIT              |
|                                                   |
|  BEFORE YOU ARRIVE:                              |
|                                                   |
|  +  Gather any previous dental records           |
|     If you have X-rays from another dentist,     |
|     bring them. They help me understand your     |
|     history without repeating scans.             |
|                                                   |
|  +  Make a list of questions                      |
|     Write down anything you want to ask.          |
|     It's easy to forget when you're in the chair.|
|                                                   |
|  +  Note your symptoms or concerns              |
|     When did the problem start? What makes it   |
|     better or worse? Is there pain?              |
|                                                   |
|  +  Bring your insurance information (if any)   |
|     Even if I don't work directly with          |
|     insurance, I can provide the invoices         |
|     you need for reimbursement.                  |
+---------------------------------------------------+
```

### Section 3: What Happens During the Visit

```
+---------------------------------------------------+
|  WHAT TO EXPECT AT YOUR FIRST VISIT              |
|                                                   |
|  DURATION: 45-60 minutes                          |
|                                                   |
|  STEP 1: Introduction (5 min)                     |
|  We'll start with a conversation. I want to      |
|  understand your concerns, your dental history,  |
|  and what you're hoping to achieve.              |
|                                                   |
|  STEP 2: Examination (20 min)                     |
|  Full examination of your teeth, gums, bite,    |
|  and any specific problem areas. I'll look at    |
|  everything, not just the thing that's bothering |
|  you.                                            |
|                                                   |
|  STEP 3: X-rays (10 min)                         |
|  If needed, I'll take digital X-rays to see      |
|  what's happening beneath the surface.           |
|  Low-radiation digital equipment.                |
|                                                   |
|  STEP 4: Discussion (15 min)                    |
|  I'll explain what I see in clear language.      |
|  You'll understand your options before any        |
|  treatment begins.                                |
|                                                   |
|  STEP 5: Treatment plan (if needed) (10 min)     |
|  If treatment is needed, I'll give you a        |
|  written plan with costs, timeline, and         |
|  alternatives. You don't have to decide today.   |
+---------------------------------------------------+
```

---

### Section 4: After the Visit

```
+---------------------------------------------------+
|  AFTER YOUR FIRST VISIT                           |
|                                                   |
|  +  You'll receive a written summary             |
|     Within 24 hours, I'll send you a WhatsApp   |
|     message with the key points from our         |
|     discussion and your treatment options.       |
|                                                   |
|  +  You can ask questions anytime                 |
|     Message me on WhatsApp if you think of       |
|     something after you leave. I respond within   |
|     24 hours on weekdays.                       |
|                                                   |
|  +  No pressure to proceed                       |
|     Take your time to decide. If you have        |
|     questions about the treatment plan, ask      |
|     before you book your next appointment.       |
|                                                   |
|  +  Next steps (if treatment is needed)          |
|     We'll schedule follow-up appointments at      |
|     a pace that works for you.                   |
+---------------------------------------------------+
```

---

### Section 5: Common Questions

```
+---------------------------------------------------+
|  COMMON QUESTIONS ABOUT THE FIRST VISIT          |
|                                                   |
|  Q: "Will it hurt?"                               |
|  A: The examination itself is not painful.       |
|  If you have a specific problem area that's       |
|  sensitive, tell me and I'll be gentle.          |
|  I don't do anything without explaining first.   |
|                                                   |
|  Q: "How much will it cost?"                     |
|  A: The first consultation is Gs 400-600k         |
|  (second opinion) or Gs 500-800k (treatment     |
|  planning). If you proceed with treatment,       |
|  this fee is credited toward your treatment cost.|
|                                                   |
|  Q: "Do I need to fast (no eating before)?"     |
|  A: No. Eat normally before your appointment.    |
|  There's no procedure in the first visit that    |
|  requires fasting.                               |
|                                                   |
|  Q: "Can someone come with me?"                  |
|  A: Yes. You're welcome to bring a companion.   |
|  They can wait in the waiting area during the   |
|  examination if you prefer, or stay if it makes  |
|  you more comfortable.                          |
+---------------------------------------------------+
```
