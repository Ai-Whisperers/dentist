# CANVA TEMPLATE SPECS — OMETZ DENTAL

## 🎯 SETUP INICIAL EN CANVA

### 1. Crear "Brand Kit" en Canva Pro (recomendado)

Ir a **Brand Kit** (esquina superior izquierda → Brand Kit) y cargar:

| Asset | Valor |
|-------|-------|
| **Logos** | Subir `logo-concept-1-ometz-protagonista.svg` + variantes |
| **Colores** | Agregar paleta oficial con hex codes |
| **Tipografías** | Agregar Montserrat (ya disponible en Canva) + Frank Ruhl Libre (si para hebreo) |

### 2. Colores cargados

```
Verde Teal Ometz:    #1A5F5A
Crema Cálido:        #FAFAF8
Terracota Dorado:    #B8860B
Carbón Suave:        #2D2D2D
Rosa Coral:          #D88C7A  (acento fechas)
```

### 3. Tipografías cargadas

```
Montserrat:           Regular, Medium, SemiBold, Bold, Black
Frank Ruhl Libre:     Regular, Bold (para אומץ — o usar "SBL Hebrew" si está)
```

## 📐 10 TEMPLATES — SPECS TÉCNICOS

### Template 1 — Quote Card (1080×1080)

**Tipo de diseño:** Instagram/Facebook Post Square
**Dimensiones:** 1080 × 1080 px
**Fondo:** Verde Teal `#1A5F5A` o Crema `#FAFAF8` (alternar)
**Tipografía:** Montserrat Bold para frase, Regular para atribución
**Elementos fijos:**
- Logo אומץ pequeño en esquina inferior derecha (50% opacity)
- Línea dorada `#B8860B` separando secciones
- "— DRA. GABY" como atribución

**Customización:**
- Cambiar frase principal
- Cambiar color de fondo (alternar teal/crema)
- Cambiar color de texto (blanco si fondo teal, carbón si fondo crema)

**Export:**
- PNG 1080×1080
- JPG 1080×1080 (alternativa menor peso)

---

### Template 2 — Carrusel Educativo (1080×1080)

**Tipo:** Carrusel Instagram (multi-slide)
**Estructura:** 5-6 slides idénticos en estructura

**Slide 1 (portada):**
- Fondo Crema `#FAFAF8`
- Título en Montserrat Bold 76pt color Teal
- Subtítulo en Regular 28pt
- Icono emoji grande centrado

**Slides 2-5 (contenido):**
- Mismo fondo
- Número grande de slide (24% opacity, dorado)
- Heading Montserrat Bold 60pt Teal
- Bullet text Montserrat Regular 26pt
- Footer "OMETZ DENTAL · TE ESCUCHO" 14pt

**Slide final (CTA):**
- Fondo Teal sólido
- Heading blanco Montserrat Bold 64pt
- CTA box dorado con texto blanco
- Messaging number

**Customización:** duplicar template, cambiar copy + número

---

### Template 3 — Servicios (1080×1080)

**Tipo:** Post Awareness
**Estructura:** Header + cuadrícula 2×2 + footer

- **Header:** Montserrat Bold 62pt Teal + línea dorada + label superior
- **Cuadrícula 2×2:**
  - 2 cards oscuras (Teal) + 2 cards claras (Crema con borde Teal)
  - 1 card de acento (Terracota)
  - Cada card: emoji/initial + título Bold 32pt + descripción Regular 18pt
- **Footer:** Messaging + dirección en Montserrat 20pt

**Customización:** solo cambiar títulos de cada servicio si cambia el catálogo

---

### Template 4 — Promo (1080×1080)

**Tipo:** Post Promocional
**Estructura:**
- Banner superior Terracota con "PROMO" en Bold 44pt blanco
- Hero emoji o icon
- Título grande
- Bloque de precio (fondo claro)
- Validity date
- CTA box Terracota con Messaging

**Compliance:**
- NO usar "50% off" agresivo
- Precio anterior tachado (sin porcentaje)
- Válido: rango de fechas
- "Cupos limitados" + "Con cita previa"

---

### Template 5 — Testimonio / Prueba Social (1080×1350)

**Tipo:** Post vertical (4:5)
**Estructura:**
- Header "Recibimos mensajes como este cada semana"
- Bloque "Messaging captura" (rectángulo redondeado con texto del paciente, sin nombre)
- Texto explicativo
- CTA Messaging

**Compliance:** nunca compartir nombre del paciente, no mostrar cara

---

### Template 6 — Story / Status 24h (1080×1920)

**Tipo:** Story vertical (9:16)
**Estructura:**
- Logo superior
- Emoji/icon grande
- Headline gigante
- Bloque de precio o info
- CTA Messaging
- Footer "Válido solo hoy"

**Variantes:**
- Promo flash (gradiente oscuro)
- Anuncio de servicio (fondo claro)
- Anuncio personal (Gaby con scrubs)

---

### Template 7 — Foto Hero Personal (1080×1080)

**Tipo:** Post "Meet the doctor" / Hero portrait
**Estructura:**
- Foto de Gaby (placeholder hasta sesión de fotos)
- Quote superpuesto o tagline
- Logo אומץ + "DRA. GABY"

**Customización:** cambiar foto cuando esté disponible

---

### Template 8 — Día Especial / Holiday (1080×1080)

**Tipo:** Post fechas especiales
**Estructura variable por fecha:**

| Fecha | Paleta dominante |
|-------|------------------|
| Día Madre | Rosa Coral + Crema |
| Día Padre | Verde Salvia + Crema |
| Navidad | Dorado + Teal |
| Año Nuevo | Teal + Dorado |
| Día Mujer | Lila + Crema |
| Día Odontólogo | Teal + Dorado |
| Día del Amigo | Amarillo + Crema |

**Estructura común:**
- Header con label fecha
- Emoji/icon representativo
- Mensaje principal
- Promo o mensaje
- CTA Messaging

---

### Template 9 — Mail Newsletter Header (600×300)

**Tipo:** Header de email
**Estructura:**
- Fondo Teal
- אומץ grande dorado centrado
- "OMETZ DENTAL" en Montserrat Bold
- Tagline "Te escucho."

**Uso:** copia y pega en el `<header>` del template HTML

---

### Template 10 — Caso Clínico / Antes-Después (1080×1080)

**Tipo:** Post caso clínico
**Estructura:**
- Header "CASO CLÍNICO · REHABILITACIÓN"
- 2 placeholders lado a lado (Antes / Después)
- Etiquetas "ANTES" (Teal) + "DESPUÉS" (Terracota)
- Descripción del caso
- Disclaimer "consentimiento firmado"

**Compliance:** nunca publicar sin consentimiento escrito

## 🎨 EXPORT OPTIONS

| Plataforma | Formato | Calidad |
|------------|---------|---------|
| Instagram/Facebook feed | PNG | 1080×1080 o 1080×1350 |
| Story / Reel | PNG/MP4 | 1080×1920 |
| Email header | PNG | 600×300 |
| Messaging catalog | PNG | 500×500 (compress) |
| Impresos (después de aprobación) | PDF print-ready | CMYK 300 DPI |

### Canva → print

Si vas a imprimir (cards, signage):
1. File → Download → PDF Print
2. Color profile: CMYK
3. Marcar "Crop marks and bleed" (3mm)

## ✅ WORKFLOW DE CREACIÓN EN CANVA

```
1. Abrir Brand Kit (esquina sup. izq.)
2. "Crear diseño" → tamaño según template
3. Aplicar paleta oficial desde Brand Kit
4. Aplicar tipografía Montserrat desde Brand Kit
5. Agregar logo desde uploads
6. Customizar copy + visual
7. Guardar en carpeta del proyecto
8. Exportar PNG + JPG
9. Subir a Drive (carpeta del mes)
10. Compartir con Kiki para aprobación
11. Si OK → publicar / usar
```
