# SISTEMA DE TEMPLATES VISUALES — OMETZ DENTAL
## Guía para community manager + diseñador (interno o externo)
**Versión:** 1.0 — Julio 2026
**Uso:** todos los visuales de Facebook, Google Business, WhatsApp, Instagram (cuando se active), email, presentations, impresos.

---

## 🎯 PROPÓSITO

Estandarizar **todos los visuales** de Ometz Dental para que:
1. La marca sea reconocible a primera vista (3 segundos).
2. Cualquier persona (community manager nuevo, diseñador externo, Gaby misma) pueda crear un visual coherente.
3. Se pueda producir en masa sin perder calidad.
4. Funcione en formato cuadrado (feed), horizontal (portada), vertical (story/reel).

- ❌ Negro puro (`#000000`) — usar Carbón Suave `#2D2D2D`

## ✍️ TIPOGRAFÍA

### Familia principal: **Montserrat**

| Uso | Variante | Tamaño | Peso | Uso ejemplo |
|-----|----------|--------|------|-------------|
| Título principal | Montserrat | 48-72pt | Bold | "Te escucho." en portada |
| Subtítulo | Montserrat | 24-32pt | SemiBold | "Rehabilitación oral + segunda opinión" |
| Cuerpo | Montserrat | 14-18pt | Regular | Texto del post en imagen |
| Caption | Montserrat | 10-12pt | Regular | "— Dra. Gabriella González Pane" |
| CTA | Montserrat | 18-22pt | Bold | "Escribime al WhatsApp" |

**Alternativa gratuita:** Inter (Google Fonts) — usar si Montserrat no está disponible.

### Familia complementaria: **Playfair Display Italic**

| Uso | Variante | Tamaño | Uso ejemplo |
|-----|----------|--------|-------------|
| Acentos | Playfair Display | 18-24pt | "אומץ — Coraje para tu boca" |
| Quotes | Playfair Display Italic | 22-32pt | "Antes de mirar tu boca, miro tu historia" |

### ❌ TIPOGRAFÍAS PROHIBIDAS

- ❌ Comic Sans, Brush Script, Papyrus — no profesionales
- ❌ Times New Roman — anticuado
- ❌ Helvetica/Arial solo — muy genérico
- ❌ Cualquier fuente con adornos innecesarios (Lobster, Pacifico)
- ❌ Fuentes con kerning apretado en tamaños grandes (luce barato)

### Template 1 — POST ESTÁNDAR "QUOTE CARD"

**Cuándo usar:** pilares P3 (voz Gaby), mensajes emotivos.
**Formato:** 1080 × 1080 px.

```
┌─────────────────────────────────────┐
│                                     │
│  [Fondo: Verde Teal Ometz #1A5F5A]  │
│                                     │
│     "Antes de mirar tu boca,        │
│      miro tu historia."             │
│                                     │
│      — DRA. GABY                    │
│                                     │
│  [Logo Ometz pequeño - inferior]    │
│                                     │
└─────────────────────────────────────┘
```

**Reglas:**
- Fondo: Verde Teal o Crema (alternar)
- Texto: Blanco si fondo oscuro, Carbón si fondo claro
- Logo: inferior derecho, 200px ancho, 50% opacidad
- אומץ hebreo: puede aparecer como marca de agua superior izquierda (opcional)
- Tipografía: Playfair Display Italic 32pt para la frase, Montserrat 14pt para "— DRA. GABY"

**Personalización:**
- Variable 1: la frase (cambiar)
- Variable 2: el color de fondo (alternar Teal/Crema)
- Variable 3: el logo color (blanco si fondo oscuro)

## 🤖 FLUJO DE PRODUCCIÓN DE VISUALES

### Paso 1 — Identificar el slot del calendario
- Abrir `calendario-marketing-2026-completo.md`.
- Para la semana entrante, identificar los 3 slots (A/B/C).
- Anotar el tipo (P1, P3, P4, P5) y la fecha clave si aplica.

### Paso 2 — Elegir el template
- P1 educativo → Template 2 (carrusel)
- P3 voz → Template 1 (quote card)
- P4 prueba social → Template 5 (testimonio)
- P5 promo → Template 4 (promo)
- Día especial → Template 9 (tarjeta fecha)
- Servicio → Template 3 (cuadrícula)

### Paso 3 — Crear en Canva
1. Login en canva.com (cuenta Ometz o Gaby personal).
2. Crear diseño desde template (los 10 templates están guardados como plantillas del equipo).
3. Customizar:
   - Texto (copy del post en `52-posts-pre-armados-anuales.md`)
   - Colores (solo de la paleta oficial)
   - Tipografía (Montserrat + Playfair Display)
   - Logo (importar como elemento)
4. Exportar como PNG (1080 × 1080 o 1200 × 630 según formato).
5. Guardar en carpeta `assets/social/[YYYY-MM-DD]/`.

### Paso 4 — Publicar
- Subir a Meta Business Suite con el copy correspondiente.
- Programar para el slot del calendario.
- Verificar el preview antes de confirmar.
