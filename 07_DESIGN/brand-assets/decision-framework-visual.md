## 🗳️ PROCESO DE DECISIÓN

### Flujo para cada decisión

```
1. Erebus presenta opciones (con justificación)
       ↓
2. Iván + Kiki revisan (3-5 días)
       ↓
3. Si hay desacuerdo → escalada (reunión 30 min)
       ↓
4. Decisión final + Acta (este documento)
       ↓
5. Implementación (con deadline)
       ↓
6. Revisión post-implementación (30 días después)
```

### Quién decide qué

| Tipo de decisión | Decide | Aprueba | Ejecuta |
|------------------|--------|---------|---------|
| Marca / identidad visual | Kiki + Iván | Gaby | Diseñador externo |
| Copy / tono comunicación | Kiki | Gaby | CM / Kiki |
| Sitio web / dev | Iván | Iván | Dev |
| Estrategia marketing | Iván + Kiki | Iván | CM |
| Operaciones / legal | Gaby | Gaby | Gaby |
| Presupuesto > USD 500 | Kiki propone | Iván aprueba | Kiki gestiona |
