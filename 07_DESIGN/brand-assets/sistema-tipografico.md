## 🔤 DECISIÓN RECOMENDADA (YA EN EL REPO)

### Familia principal: **Montserrat**
- **Licencia:** Open Font License (Google Fonts) — gratis, sin restricciones
- **Pesos disponibles:** Thin, ExtraLight, Light, Regular, Medium, SemiBold, Bold, ExtraBold, Black
- **Estilos:** Regular + Italic en cada peso
- **Lenguaje:** Latina extendido (todos los acentos y caracteres PY/ES + EN)
- **Por qué:** universal, legible en mobile, 9 pesos dan mucha flexibilidad, está aprobada en el repo

### Familia secundaria (opcional): **decisión pendiente**

| Opción | Familia | Por qué sí | Por qué no | Recomendación |
|--------|---------|------------|-----------|---------------|
| A | **Solo Montserrat** (varios pesos) | Coherencia máxima, gratis | Menos personalidad, más "tech" | ✅ Default |
| B | **DM Serif Display** (Google Fonts) | Contraste alto, editorial | Más caro de mantener | Para hero/titulares solamente |
| C | **Playfair Display Italic** (Google Fonts) | Elegante, italiana clásica | Puede sentirse anticuado | 🟡 Si Gaby lo aprueba |
| D | **Cormorant Garamond** | Lujo, editorial | Cuesta leer en mobile | ❌ No para body |

**Recomendación Erebus:** **A (solo Montserrat)** para máxima consistencia. Si Gaby/Kiki sienten que falta personalidad en hero, agregar **B (DM Serif Display) SOLO para titulares grandes**.

## 🎨 PARES TIPOGRÁFICOS RECOMENDADOS

### Pair 1 — MODERN CONSERVATIVE (recomendado)
```
H1:     Montserrat Bold 64pt       ←──→
Body:   Montserrat Regular 18pt
CTA:    Montserrat SemiBold 20pt
```
**Sensación:** limpio, moderno, confiable. Estilo Apple Health / Tend / Beehive.
**Cuándo usarlo:** todo el sitio web, app, posts de feed.

### Pair 2 — EDITORIAL SOUL (alternativa con serifa)
```
H1:     DM Serif Display 64pt      ←──→
Body:   Montserrat Regular 18pt
CTA:    Montserrat SemiBold 20pt
```
**Sensación:** premium, editorial, magazine. Estilo Grand Street Dental / Zen.
**Cuándo usarlo:** hero del sitio, landing pages especiales, posts de品牌形象.

### Pair 3 — QUIET AUTHORITY (alternativa sobria)
```
H1:     Montserrat ExtraLight 64pt ←──→
Body:   Montserrat Regular 18pt
CTA:    Montserrat SemiBold 20pt
```
**Sensación:** sobrio, técnico, doctor. Estilo hospital premium / Wexford.
**Cuándo usarlo:** si Gaby quiere proyectar más autoridad clínica.

## 📐 REGLAS DE USO

### ✅ HACER

1. **Máximo 2 niveles de jerarquía por bloque visual.** Si tenés H1 + H2 + body + caption, simplificar.
2. **Usar el mismo peso de body en todo el sitio web.** Coherencia.
3. **Line-height generoso en body** (1.5-1.6). Mejora legibilidad.
4. **Letter-spacing amplio en mayúsculas**. En Montserrat Bold all-caps, +50 a +100 de letter-spacing.
5. **Italics SOLO para énfasis sutil o quotes.** No abusar.
6. **Ancho de línea 50-75 caracteres** en body. Más corto = ilegible, más largo = agotador.

### ❌ NO HACER

1. **NO mezclar más de 2 familias** tipográficas en un mismo artefacto (ej. sitio web).
2. **NO usar Light/Thin para body** — ilegible en mobile.
3. **NO usar Bold para párrafos largos** — cansa la vista.
4. **NO usar ALL CAPS para más de 2 palabras seguidas** — grita.
5. **NO usar italics para texto legal** — ilegible.
6. **NO estirar ni comprimir** la tipografía manualmente (cambia las proporciones).
7. **NO usar más de 3 colores tipográficos** en un mismo artefacto (ej. texto principal + acento + CTA).
8. **NO usar tamaños <12pt en impreso** — ilegible para >40 años.
9. **NO usar comillas tipográficas vs. tipográficas mezcladas** — elegir una y ser consistente.

## 🌐 WEB — IMPLEMENTACIÓN TÉCNICA

### Cómo cargar Montserrat en web

```html
<!-- Google Fonts (recomendado) -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Montserrat:ital,wght@0,300;0,400;0,500;0,600;0,700;0,800;1,400;1,500&display=swap" rel="stylesheet">
```

### Tailwind config

```javascript
// tailwind.config.js
module.exports = {
  theme: {
    fontFamily: {
      'sans': ['Montserrat', 'system-ui', 'sans-serif'],
      'serif': ['DM Serif Display', 'Georgia', 'serif'], // si se usa
    },
    fontSize: {
      'xs': ['0.75rem', { lineHeight: '1.4' }],      // 12pt
      'sm': ['0.875rem', { lineHeight: '1.5' }],    // 14pt
      'base': ['1rem', { lineHeight: '1.6' }],        // 16pt
      'lg': ['1.125rem', { lineHeight: '1.6' }],    // 18pt
      'xl': ['1.25rem', { lineHeight: '1.5' }],      // 20pt
      '2xl': ['1.5rem', { lineHeight: '1.4' }],      // 24pt
      '3xl': ['1.875rem', { lineHeight: '1.3' }],   // 30pt
      '4xl': ['2.25rem', { lineHeight: '1.2' }],    // 36pt
      '5xl': ['3rem', { lineHeight: '1.1' }],        // 48pt
      '6xl': ['3.75rem', { lineHeight: '1.1' }],    // 60pt
      '7xl': ['4.5rem', { lineHeight: '1.0' }],      // 72pt
    },
  },
};
```

### CSS custom properties

```css
:root {
  --font-primary: 'Montserrat', system-ui, sans-serif;
  --font-display: 'DM Serif Display', Georgia, serif; /* si se usa */

  --fs-h3: clamp(1.375rem, 2.5vw, 2rem);
```

## 🎯 ACCESIBILIDAD (WCAG 2.2 AA)

| Regla | Implementación |
|-------|----------------|
| **Tamaño mínimo texto** | 16pt body / 14pt caption |
| **Contraste mínimo** | Texto principal 4.5:1 contra fondo |
| **Contraste texto grande** | Texto >24pt 3:1 contra fondo |
| **Line-height** | 1.5+ en body |
| **Line-width** | 50-75 caracteres |
| **Espaciado letras** | +0.12em en small caps |
| **No texto en imágenes** (excepto logos) | Sí |

Verificador automático: WebAIM Contrast Checker (webaim.org/resources/contrastchecker/).
