## ⚙️ CONFIGURACIÓN DE GENERADORES

### Midjourney

```
/imagine [prompt] --ar 1:1 --style raw --v 6 --s 250 --q 2
```

- `--style raw`: menos "embellecimiento" automático
- `--s 250`: estilarización media-alta
- `--q 2`: máxima calidad
- `--ar 1:1` para feed / `16:9` para hero / `9:16` para story

### DALL-E 3

- Usar como está, el prompt completo.
- Pedir "Editorial photography" siempre.
- Pedir "NOT stock photo" para evitar el cliché.

### Flux (vía Replicate)

```
go_fast: false
num_inference_steps: 50
guidance_scale: 7.5
aspect_ratio: "1:1"
output_quality: 95
```

### Ideogram

- Prompt en inglés
- Pedir "photo" no "illustration"
- Aspect ratio 1:1, 4:3, 16:9 según uso

## 🚫 LO QUE NO GENERAR CON IA

| No generar | Por qué |
|------------|---------|
| "Foto de Gaby" para uso oficial | Necesita ser real para credibilidad legal y de marca |
| "Foto del consultorio real" para web | Necesita ser el consultorio real para que los pacientes lo reconozcan |
| Antes/después de casos clínicos | Éticamente cuestionable, además de fácil de detectar como IA |
| Testimonios visuales de pacientes | Ídem |
| Cualquier foto con cara identificable | Compliance MSPBS + privacidad |
