- Techo de crecimiento bajo
- Inconsistente con ADN (mezcla volumen + premium)

### Opción B — Paralelo (RECOMENDADA, operativa por default) ⭐
- Mantiene O3 como flujo de caja + práctica privada evenings/weekends
- **Decisión ya tomada** (pivote psicológico 22 jun)
- Inversión inicial: Gs 1-2M (EAS + licencia + web + POS)
- OpEx mensual: Gs 1.3-2.1M (alquiler + mantenimiento + marketing)
- Break-even: 12-15 pacientes/mes (lean) o 20-30 (full OpEx)
- Revenue scenario: 15 pac × Gs 400k = Gs 6M revenue, Gs 4.2M net

### Opción C — Full exit (después de validar B)
- Inversión: Gs 215-430M (alquiler 6-12m + equipos + branding + working capital)
- OpEx: Gs 43-75M/mes (sueldos staff Gs 15-25M + insumos Gs 15-25M + alquiler Gs 8-15M + admin Gs 5-10M)
- Break-even: 30-35 pacientes private-pay/mes

### Runway analysis (escenario lento, 6 meses a break-even)
- **Reserva mínima necesaria: Gs 17-20M** (worst case)
- Con menos de Gs 10M: NO viable sin O3 income o partnership/loan
- Plan: continuar O3 mientras valida B
