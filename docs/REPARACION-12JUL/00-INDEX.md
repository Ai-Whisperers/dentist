## 🚨 Reglas del documento

1. **Status binario.** ✅ aplicado · 🟡 parcial · ❌ pendiente · ⚠️ stale (no refleja realidad) · 🚫 descartar (no se va a hacer).
2. **Con fecha.** Cada status lleva fecha de cuándo se verificó (no cuándo se escribió el doc).
3. **Con owner.** Cada item tiene un responsable claro (Gaby, Kiki, Iván, Erebus, sistema).
4. **Consecuencia operativa.** No "hay que mejorar X". "Gaby tiene que hacer X antes del 26 jul".
5. **Sin contradicción.** Si 2 docs dicen cosas distintas, gano el más reciente + el más cerca de la realidad operativa.
