## 2. CRON Automation Spec

### 2.1 Job Definition
Name: `dentist-site-content-sync`  
Type: daily  
Schedule: `0 9 * * *`  
No-agent: false

### 2.2 Prompt
```
You are maintaining the dentist site content package. Your goals:

1. Re-scan `content/` for JSON schema compliance.
2. Verify news site data in `content/` matches canonical docs in:
   - `00_STRATEGIC/financial-pricing/canonical-pricing-reference-v2.md`
   - `05_OPERATIONS/patient-communications/patient-faq-20-answers.md`
3. Generate a fresh `REPORT.md` in repo root with:
   - Schema pass/fail flags
   - Pages found vs missing
   - Placeholder image audit
   - Any broken hrefs or missing bundle link targets
4. If fixes are trivial (e.g. missing trailing comma), patch them; otherwise list issues only.
5. Append daily sync timestamp + summary.
```

### 2.3 Expected Output
- `REPORT.md` updated with today’s sync
- `README.md` refreshed if route summary changes
- Zero manual intervention unless schema fails.
