## 🚨 SEÑALES DE ALARMA (qué vigilar)

### Señales rojas (actuar inmediatamente)

| Señal | Acción |
|-------|--------|
| <5 pacientes/mes por 2 meses consecutivos | Pivotar: cambiar propuesta valor o canales |
| Revenue no crece 3 meses seguidos | Revisar pricing + implementar promos |
| Cancelaciones >20% | Problema en proceso de agenda o calidad |
| Reseñas negativas repetidas | Problema real, ejecutar protocolo |
| Auxiliar se va antes de 6 meses | Revisar sueldo + condiciones |

### Señales amarillas (vigilar de cerca)

| Señal | Acción |
|-------|--------|
| Crecimiento <10% mes a mes | Aumentar presupuesto ads |
| ROAS <1.5x | Pausar campañas no rentables |
| CPL >USD 5 | Revisar audiencias + creativos |
| Recurrencia <25% | Mejorar seguimiento post-consulta |
| Engagement <3% | Cambiar formato / hora de publicación |

### Señales verdes (acelerar)

| Señal | Acción |
|-------|--------|
| Crecimiento >20% mes a mes | Invertir más en lo que está funcionando |
| ROAS >3x | Escalar presupuesto 30% |
| Referidos >30% | Crear programa formal de referidos |
| Engagement >7% | Aumentar frecuencia de publicación |
| Margen >40% | Evaluar expansión |

## 🔀 PLANES DE CONTINGENCIA

### Plan A — Si todo va bien (probabilidad 30%)

- Mes 6: break-even

- Decisión: abrir segunda sede en Luque / San Lorenzo

### Plan B — Si marcha según plan (probabilidad 50%)

- Mes 9: break-even (con 3 meses de retraso)
- Mes 12: 80-100 pacientes, Gs 18M revenue mensual
- Decisión: consolidar y optimizar márgenes

### Plan C — Si va peor de lo esperado (probabilidad 18%)

- Mes 6: todavía <30 pacientes/mes
- Mes 12: 50-70 pacientes, Gs 12M revenue
- Acción: evaluar reasons + pivotar (más coaching, menos marketing digital)

### Plan D — Plan de crisis (probabilidad 2%)

- Mes 6: <15 pacientes/mes, ingresos <Gs 5M
- Acción: turnos solo medio día, reducir costos fijos, evaluar cierre
- Plan B activado: convertir activo en coaching 100%
