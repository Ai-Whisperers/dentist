## REORDER RULES

### Minimum Stock Levels (Never Let It Get Below)
Set minimum level for each item. When stock hits minimum → reorder immediately.

### Order Frequency
- **Consumables**: Monthly (first week of month)
- **Materials**: Every 3 months (Jan, Apr, Jul, Oct)
- **Instruments**: Annually or when worn
- **Emergency order**: If stock hits zero between regular orders

### Ordering Process
1. Check inventory on 1st of month
2. Write order list (what's below minimum)
3. Call/WhatsApp vendor
4. Confirm price and delivery time
5. Place order
6. Update "Last Ordered" in tracker

## EMERGENCY SUPPLIES (Never Run Out)

These items are critical — keep backup stock at all times:
- Anestesia
- Resina composite (at least 3 shades)
- Guantes
- Gasa
- Antiséptico

If any of these reach zero → stop patient care and restock immediately.

---

## STORAGE RULES

1. Everything labeled with name and date
2. Temperature-controlled (not in car)
3. No direct sunlight on materials
4. First in, first out (FIFO)
5. Check expiration dates monthly
6. Discard expired materials properly
