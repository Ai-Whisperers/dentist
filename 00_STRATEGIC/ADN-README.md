## Qué es

Este documento **no es publicidad; es el sistema operativo de una identidad profesional.** No es un currículum. Es el mapa profundo desde el cual se crean piezas externas simples, claras y potentes.

### Lo que contiene (estructura)

- **30 secciones** de filosofía, principios, paciente ideal, tono de voz, lista prohibida, formatos de contenido, guías para reels/blog/WhatsApp/web, instrucciones para IAs, prompts para Iván, sistema de captación, métricas, identidad no negociable.
- **15 anexos operativos:** resumen ejecutivo, 30 hooks listos para testear, mensaje a Iván, adendum operativo, oferta inicial, calendario 30 días, guiones de video, matriz paciente-mensaje, lenguaje antes/después, manifiestos (público + interno), brief para diseñador, arquitectura web sugerida, FAQs con tono Gabriela, prompt maestro final.

## Cómo NO usar este documento

- ❌ No generar marketing odontológico genérico.
- ❌ No usar frases prohibidas ("carillas sin tallar", "sonrisa perfecta", "precio imperdible", "cambiá tu vida en una cita").
- ❌ No usar emojis en exceso ni tono de "community manager genérico".
- ❌ No inventar procedimientos o precios fuera de `00_STRATEGIC/financial-pricing/canonical-pricing-reference-v2.md`.
- ❌ No competir por precio bajo.
- ❌ No prometer perfección.
