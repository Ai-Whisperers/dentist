# FIRST PATIENT DAY CHECKLIST
## Dra. Gabriella González Pane — Everything to Set Up Before First Patient
**Version:** 1.0 — June 2026

---

## PURPOSE

The complete checklist for everything needed before the first patient walks in. Do this the evening before and the morning of.

---

## 24 HOURS BEFORE

### Evening Before — Supplies Check
- [ ] All consumables stocked (gloves, masks, gauze, cotton)
- [ ] Anesthesia stocked (at least 5 carpules)
- [ ] All resin shades available (A2, A3, A4)
- [ ] Sterilization completed (autoclave run)
- [ ] Instruments set for tomorrow's procedures
- [ ] Local anesthetic + syringes ready
- [ ] Cotton rolls, bite blocks, wedges
- [ ] Impression materials (if needed)

### Evening Before — Systems Check
- [ ] WhatsApp working and charged
- [ ] Phone charged
- [ ] Calendar shows tomorrow's appointments
- [ ] CRM open and ready
- [ ] Printer has paper (consent forms)
- [ ] Flashlight/headlamp charged (if using)

### Evening Before — Space Check
- [ ] Clinic space clean (all surfaces)
- [ ] Bathroom clean and supplied
- [ ] Waiting area tidy
- [ ] Signage visible (if installed)
- [ ] Business cards available (if installed)
- [ ] Temperature comfortable (AC/heater)

---

## MORNING OF — 90 MINUTES BEFORE FIRST PATIENT

### 90 min — Treatment Room
- [ ] Lay out instruments for first procedure
- [ ] Set up high volume evacuator
- [ ] Check handpiece connections
- [ ] Test handpiece air/water
- [ ] Set up chair light
- [ ] Position patient chair correctly
- [ ] Have patient glasses ready
- [ ] Have suction tips ready
- [ ] CheckRX machine (if using today)

### 60 min — Reception / Admin
- [ ] Print consent forms (5 copies minimum)
- [ ] Print intake forms (5 copies minimum)
- [ ] Have pens available
- [ ] Set up payment processing (Pagopar/Bancard tested)
- [ ] Post-treatment instructions printed (generic)
- [ ] Business cards on counter

### 45 min — Communication
- [ ] Send appointment reminders to today's patients (24h before)
- [ ] WhatsApp auto-responses working
- [ ] Emergency contact info visible
- [ ] Dra. GP WhatsApp accessible

### 30 min — Personal
- [ ] Professional attire ready
- [ ] Hair tied back if needed
- [ ] Personal phone on silent (business WhatsApp still active)
- [ ] Coffee/water nearby (don't dehydrate)

---

## JUST BEFORE PATIENT ARRIVES

### 10 min — Final Setup
- [ ] Wash hands
- [ ] Turn on "Abierto" sign (if have one)
- [ ] Check yourself in mirror
- [ ] Clear all personal items from treatment area
- [ ] Close all cabinets so patient doesn't knock things over
- [ ] Take a breath

---

## DURING PATIENT

### Patient Arrives
- [ ] Greet warmly by name (you should have reviewed their name)
- [ ] Offer to hang coat/bag
- [ ] Offer water if waiting area has it
- [ ] Ask them to complete intake form
- [ ] While they fill form, prepare for consultation

### During Treatment
- [ ] Explain what you're doing (don't surprise them)
- [ ] Give breaks if needed ("tomá un respiro")
- [ ] Check in: "¿Estás bien?"
- [ ] Keep conversation minimal during sensitive work

### After Treatment
- [ ] Explain post-treatment care verbally
- [ ] Hand them written post-treatment instructions
- [ ] Confirm next appointment or set recall
- [ ] Explain payment (cash, transfer, Pagopar)
- [ ] Collect payment
- [ ] Walk them to reception
- [ ] Schedule next visit before they leave (if needed)
- [ ] Thank them warmly

---

## AFTER PATIENT LEAVES

### Immediately
- [ ] Write clinical notes (before you forget)
- [ ] Update CRM (contact logged, appointment attended)
- [ ] Log any payments received
- [ ] Clean operatory (surface wipe, instrument removal)
- [ ] Start sterilization for used instruments
- [ ] Restock anything used

### End of Day
- [ ] Send follow-up WhatsApp to today's patients (E1 template)
- [ ] Review tomorrow's appointments
- [ ] Send appointment reminders for tomorrow
- [ ] Check supplies — what needs reordering?
- [ ] Final sterilization run
- [ ] Lock up

## FIRST PATIENT FAQ

### What if the patient doesn't show up?
- Log as no-show in CRM
- Send "last chance" message (don't burn bridge)
- Don't take it personally

### What if there's an emergency during treatment?
- Follow emergency protocol (operations/emergency-protocol.md)
- Call 141 if needed
- Alert Dra. GP's emergency contact

### What if patient is in severe pain?
- See emergency protocol
- Assess — can you fit them in today?
- If yes: work them in somehow
- If no: refer to Hospital Clínicas

### What if patient asks for something you can't provide?
- Be honest: "No tengo eso disponible ahora"
- Refer to where they can get it
- Don't compromise on care

## PACKING LIST FOR MOBILE/EMERGENCY

If you ever need to see a patient outside the clinic:

- [ ] Portable dental kit (basic examination)
- [ ] Flashlight/headlamp
- [ ] Disposable mirrors
- [ ] Gloves, masks
- [ ] Basic medication kit
- [ ] Emergency contact list
- [ ] Portable suction (if possible)

## WHAT TO DO IF YOU FORGOT SOMETHING

| Forgot | Solution |
|--------|----------|
| Gloves | Double up or reschedule |
| Anesthesia | Can't work — reschedule |
| Impression material | Can usually borrow from nearby clinic |
| Paperwork | Use blank paper + write |
| Payment terminal | Take cash/transfer only |
