## DENTAL EMERGENCIES

### Emergency Types and Responses

| Situation | Immediate Action | Follow-up |
|-----------|------------------|-----------|
| Severe bleeding (post-op) | Apply pressure. Call patient. If can't control, go to Hospital de Clínicas Emergency (Av. San Martín 625, 021-000) | Follow up 24h |
| Swelling with fever | Antibiotic protocol or refer. Call patient, assess severity. If breathing compromised, call 141 | Schedule for evaluation ASAP |
| Severe pain (9-10/10) | Pain management protocol. Emergency appointment or refer to Hospital Emergency | Follow up next day |
| Trauma (tooth knocked out) | Instructions: put tooth in milk, come immediately. Call ahead to alert | Follow up 48h |
| Lost crown/bridge | Temporary cement instructions. Schedule re-cement ASAP | Check if underlying damage |
| Lost filling | Sensitivity management. Schedule replacement ASAP | Monitor |
| Broken tooth with sharp edge | Smooth if possible, or dental wax to protect cheek. Schedule | Check pulp exposure |
| Anaphylaxis (allergy reaction) | Call 141. Go to Hospital de Clínicas emergency NOW | Document, review |

### Hospital de Clínicas Emergency Info
- Address: Av. San Martín 625, Asunción
- Phone: (021) 000-000 (ER dental)
- Available 24/7
- Free for public
- For severe dental emergencies only

### Common Dental Emergency Medications
| Medication | Indication | Dose |
|------------|------------|------|
| Amoxicilina 500mg | Infection with swelling | 500mg every 8h x 7 days |
| Ibuprofeno 400mg | Pain/inflammation | 400mg every 6h |
| Metronidazol 500mg | Severe infection | 500mg every 8h x 7 days |
| Dipirona 500mg | Severe pain + fever | 500mg every 6h |

**NOTE:** Only prescribe if legally authorized. Otherwise, refer to Hospital.

## OPERATIONAL EMERGENCIES

### Equipment Failure
| Equipment | Immediate | Short-term | Long-term |
|-----------|-----------|------------|-----------|
| Autoclave broken | Use disposable instruments. No sterilization | Call repair service | Get loaner or replacement |
| Chair won't work | Reschedule non-urgent patients | Call technician | Preventive maintenance |
| RX machine down | Don't take X-rays. Manual examination. Refer for radiographs if critical | Call repair service | — |
| Computer/CRM down | Use phone + paper backup | Restore from backup | IT support |

### Computer/Phone Emergency
| Situation | Action |
|-----------|--------|
| Phone died | Use backup phone. Contact Hermes agent via alternate device |
| WhatsApp blocked | Switch to regular WhatsApp temporarily. Update contacts |
| CRM offline | Use paper backup (printed contact list) until restored |
| Lost phone | Log into WhatsApp Web from another device immediately |

## WHAT TO DO IF...

### If a Patient Dies During Treatment
1. Call 141 immediately (legal obligation)
2. Do not move the body
3. Preserve all clinical records
4. Call lawyer within 1 hour
5. Do not speak to media or anyone except police/lawyer

### If Patient Has Adverse Reaction
1. Stop treatment immediately
2. Assess severity
3. If severe → 141 or emergency services
4. If mild → manage in office, monitor
5. Document everything
6. Follow up within 24h

### If Equipment Causes Injury
1. Ensure patient safety first
2. Document what happened
3. Remove equipment from use
4. Contact manufacturer
5. Contact lawyer

### If WhatsApp Gets Banned (Spam Reports)
1. Don't panic — happens sometimes
2. Appeal via Meta Business Manager
3. Use regular WhatsApp while appeal processes
4. Inform patients of alternate contact

### If Hermes Agent Goes Down
1. Check if server running
2. Restart agent service
3. Manually respond to all pending messages
4. Inform Dra. GP if sustained outage
5. Fall back to manual response mode

## COMMUNICATION IN EMERGENCY

**For patient emergencies:**
- First: Call patient (phone > WhatsApp)
- If can't reach: WhatsApp message + leave voicemail
- Document all attempts in CRM

**For operational emergencies:**
- Dra. GP notified immediately via phone call (not WhatsApp)
- Hermes agent alerts via configured emergency channel
