## 3. LESSON CATALOG

### 21–40 · HERO / FIRST SCREEN
21. Use benefit-first headline, not “Welcome to our practice”
22. Lead with patient’s problem, not doctor’s credentials
23. Add a single primary CTA button above the fold
24. Add a WhatsApp bubble from hero section
25. Add bilingual badge from first screen if targeting expats
26. Use background video or calm office still only, avoid dental tool macro shots
27. Show trust markers: years exp, patient count, languages
28. Keep hero headline under 10 words
29. Avoid clinical blue unless brand already owns it
30. Use dark/teal/gold premium palette for authority, not sterile white+blue
31. Place phone number on top-right, sticky
32. Add “Free second opinion” as hero badge when possible
33. Use lowercase headings to signal modernity
34. Avoid dental stock “perfect smile” — use real environment photos
35. Show location signal near phone CTA
36. Add one-line promise like “No pressure, written plan”
37. Use 3-slide max carousel to avoid decision fatigue
38. Add French/English toggle at top level if serving expats
39. Include “Quote in 24h” or “Same-week availability” claim
40. Use teal + gold for premium feel; white for cleanliness

### 41–60 · NAVIGATION / UX
41. Reduce primary nav to 5 items max
42. Show services grouped by outcome, not specialty
43. Add prices table or starting price signals where legal
44. Always show booking flow: message → visit → plan
45. Use sticky nav with transparent-to-solid transition
46. Hide “Home” label on homepage
47. Use 2-level dropdown for services only
48. Add glossario/FAQ as top tab for anxious patients
49. Place emergency contact as always-visible floating button
50. Add top bar for hours and phone
51. Add language switcher in header
52. Include “How to get here” as subitem under Contacto
53. Avoid mega menu unless 50+ services
54. Put corporate/empresas link in footer
55. Show current wait/availability next to “Book”
56. Link WhatsApp button directly to message template
57. Offer “Request callback” as secondary action
58. Add search box only if 100+ content pages
59. Show breadcrumbs on deep pages
60. Hide nav entirely on landing pages, single CTA only

### 61–80 · SERVICES / PRICING DESIGN
61. Present pricing in grouped tables with clear headers
62. Add disclaimer: “Precios referenciales, se confirman en consulta”
63. Show 3 tiers/options per service when possible
64. Add “Financing/bank/Pagopar” next to prices
65. Use icons, not bullet lists, on service cards
66. Include duration on every service item
67. Show before/after slider only if consent exists
68. Offer download PDF quote at end of service page
69. Add bundle pricing for corporate packages
70. Show “Second opinion” as standalone premium
71. Use gray disabled state for unavailable services
72. Include package comparison for ortho/implants
73. Show package price vs itemized price
74. Highlight “Costo final sin sorpresas”
75. Add financing calculator widget if legal
76. Show related services at foot of each category
77. Group pediatric vs adult services explicitly
78. Add taboo/service boundary page: “When we refer out”
79. Show insurance/reimbursement notes where relevant
80. Include urgency triage labels: mild/moderate/severe

### 81–100 · TESTIMONIALS / SOCIAL PROOF
81. Use 8–12 testimonials max on homepage
82. Include initials + date for privacy
83. Add service tag under quote
84. Show stars + text; show video when possible
85. Use patient quote size bigger than name
86. Add “Google review” source badge near carousel
87. Add mobile-native stories-style showcase
88. Include negative review response template (transparency page)
89. Show geographic diversity: Asunción, Luque, expats
90. Add before/after consent pair under testimonial
91. Use rotating carousel; avoid grid-only
92. Emphasize bilingual/English mentions
93. Show “Patient since” date for long-term trust
94. Add referral source question in intake form
95. Use case study expander: problem → treatment → result
96. Link testimonial to service page anchor
97. Add Google Maps rating badge in footer
98. ShowAverage review score next to booking CTA
99. Use real photos; fallback is colored initials, not stock people
100. Highlight second-opinion success story specifically

### 161–180 · DESIGN / VISUAL QUALITY
161. Use max 3 font families
162. Stick to 60-30-10 color rule
163. Use rounded corners in moderation
164. Add consistent icon set
165. Use dark navy + teal + gold palette tested with WCAG AA
166. Add subtle texture in background to avoid flat sterile feel
167. Use serious photography: doctors working, not models
168. Maintain mobile viewport with scaled type
169. Add hover state to every interactive element
170. Use white space to slow reader down
171. Add progress indicator on long forms
172. Use CSS-based animation for performance
173. Avoid parallax on mobile
174. Use lazy loading below the fold
175. Show consistent card height in grids
176. Use site-wide one shadow system
177. Add dark-mode-ready color palette
178. Keep buttons minimum 44px height
179. Use detectable focus rings
180. Add micro-interactions: checklist ticks, gentle fade-ins
