## 🎙️ Formato de respuesta en audio

### Opción A — Por letra

```
09.P5: B
09.P6: B
09.P9: B
13.P21: A
05.P1: A
```

### Opción B — Narrativo

```
En 09 P5 elijo B (no, iniciar trámite), P6 también B, P9 B (contratar esta semana), en 13 P21 A (pendiente), en 05 P1 A (esta semana).
```

### Opción C — Solo bloqueantes (5 min)

```
09.P3: B (no alquila, no EAS)
09.P5: B (iniciar trámite)
09.P6: B (iniciar trámite)
09.P9: B (contratar RC)
13.P10: A (Iván esta semana)
13.P12: A (Iván esta semana)
13.P21: A (pendiente esta semana)
05.P1: A (esta semana)
```

### Opción D — "Todo A" (más rápido)

```
Cuestionario 02: todo A
Cuestionario 05: todo A
Cuestionario 07: todo A
Cuestionario 09: todo A
Cuestionario 13: todo A
```

> Si decís "todo A" se elige la primera opción de cada pregunta.
