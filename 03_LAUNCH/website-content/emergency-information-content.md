## RECOMMENDED STRUCTURE

### Section 1: What IS a Dental Emergency

```
+---------------------------------------------------+
|  DENTAL EMERGENCIES I CAN HELP WITH              |
|                                                   |
|  +  Severe toothache that won't stop             |
|  +  Swelling in the mouth or face                |
|  +  Broken or cracked tooth from trauma          |
|  +  Knocked-out tooth (call immediately)          |
|  +  Bleeding that won't stop after extraction    |
|  +  Lost crown or temporary filling              |
|                                                   |
|  RESPONSE: I respond to emergency messages       |
|  within 1-2 hours on weekdays.                  |
+---------------------------------------------------+
```

---

### Section 2: What Is NOT a Dental Emergency

```
+---------------------------------------------------+
|  DON'T GO TO THE ER UNLESS:                      |
|                                                   |
|  +  Severe facial trauma with suspected broken   |
|     jaw                                         |
|  +  Swelling spreading toward eye or neck        |
|  +  Can't breathe or swallow due to swelling    |
+---------------------------------------------------+
```

---

### Section 3: Immediate Relief While Waiting

```
+---------------------------------------------------+
|  FOR SEVERE TOOTHACHE:                           |
|  - Rinse with warm water                         |
|  - Floss gently                                  |
|  - Take ibuprofen as directed                    |
|  - DO NOT put aspirin directly on gum           |
|                                                   |
|  FOR SWELLING:                                   |
|  - Apply cold compress to outside of cheek      |
|  - Rinse with salt water                        |
|  - Do NOT apply heat                            |
|                                                   |
|  FOR KNOCKED-OUT TOOTH:                          |
|  - Handle by crown (not root)                    |
|  - Store in milk or saliva                       |
|  - CALL IMMEDIATELY                              |
+---------------------------------------------------+
```
