## PURPOSE & CONVERSION GOAL

**Job:** Reduce first-visit anxiety by setting clear expectations before the appointment.

**Conversion goal:** Reduce "no-show" rate by 20%. Increase patient satisfaction with first visit experience by 30%.

## TARGET AUDIENCE

1. **First-time patients** — never been to this practice, anxious about what happens
2. **Nervous/anxious patients** — dental anxiety is real
3. **Efficient patients** — who want to maximize their time, arrive prepared

## RECOMMENDED STRUCTURE

### Section 1: Before Your Appointment

\`\`\`
+---------------------------------------------------+
|  HOW TO PREPARE FOR YOUR FIRST VISIT              |
|                                                   |
|  +  Gather any previous dental records           |
     Bring X-rays from another dentist if you     |
     have them.                                   |
|                                                   |
|  +  Make a list of questions                      |
     Write down anything you want to ask.          |
|                                                   |
|  +  Note your symptoms or concerns              |
     When did the problem start? What makes it   |
     better or worse?                             |
|                                                   |
|  +  Bring your insurance information (if any)   |
+---------------------------------------------------+
\`\`\`
