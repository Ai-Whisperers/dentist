## PURPOSE & CONVERSION GOAL

**Job:** Convert skeptical visitors into contacters by proving credibility without resorting to hollow claims.

The visitor has a question in their head: *"Can I trust this dentist?"* Social proof answers that question before they ask. It must feel earned, not manufactured — authentic testimonials, real credentials, transparent numbers. Trust is built through specificity, not superlatives.

**Conversion goal:** Increase contact rate by 40% for visitors who scroll past the hero. Works for both expat and local Paraguayan audiences.

---

## TARGET AUDIENCE

1. **Local Asunción patients** — looking for a dentist they can trust with their family. They scan for: experience, certifications, what other patients say.
2. **Expat/English-speaking patients** — skeptical of Paraguayan dental quality. They need: English fluency proof, international benchmarking, testimonials from other expats.
3. **Treatment-anxious patients** — afraid of overtreatment or being upsold. They need: transparency, "what I won't do" signals, conservative philosophy confirmation.

## RECOMMENDED STRUCTURE

### Section 1: Numbers That Matter (above the fold)

Display 3-4 verified stats prominently — not vanity metrics, real proof points:

```
+---------------------------------------------------+
|  +---------+   +---------+   +---------+          |
|  |   20    |   |  2,400+ |   |   98%   |          |
|  |  years  |   | patients|   | patient |          |
|  |experience|  | treated |   |satisfaction|      |
|  +---------+   +---------+   +---------+          |
+---------------------------------------------------+
```

**Why these numbers:**
- "20 years" = credibility without bragging
- "2,400+ patients" = volume proof without being a chain
- "98% satisfaction" = quality signal (only use if we have real data)

**Note:** Use real numbers only. Do not invent stats. If you don't have verified data, use qualifiers: "hundreds of patients," "two decades of experience."

### Section 2: Google Reviews (Social proof engine)

```
+---------------------------------------------------+
|  +5  "She explained everything before starting.   |
|       No pressure. Best dentist I've had."        |
|       -- Maria T., Google Review                  |
|                                                   |
|  +5  "Finally a dentist who speaks English        |
|       and doesn't push procedures you don't need."|
|       -- Robert K., Google Review                |
|                                                   |
|  [View all 47 reviews on Google ->]               |
+---------------------------------------------------+
```

**Implementation:**
- Embed Google reviews widget OR static quotes with link to Google profile
- Show 2-3 reviews at a time, rotating
- Include full name (first + last initial) and verification source
- Link to Google Business profile -- this boosts local SEO

**Best practice:** DO NOT fabricate reviews. Use real ones. If you don't have reviews yet, use a placeholder: "First reviews coming soon -- [leave a review on Google]" -- this is honest and invites first reviews.

### Section 3: Patient Testimonials (Longer quotes)

Format: short video testimonial OR text quote with context

**Text testimonial structure:**
```
+---------------------------------------------------+
|  "I was told I needed 4 crowns and a root canal.  |
|   Dra. GP looked at my X-rays and said only 1 was |
|   necessary. She saved me Gs 8M and I still have  |
|   my own teeth."                                  |
|                                                   |
|  -- Carolina M., Asunción                          |
|    Patient since 2019                            |
+---------------------------------------------------+
```

**Categories to feature:**
1. Second opinion patient (proves the value of the service)
2. Family patient (she treats children/adults)
3. Expat patient (bilingual credibility)
4. Complex case (rehabilitation success)
5. Anxious patient (trust-building, sedation options)

**Source:** Always attribute with full name or first name + last initial + city. "-- Carolina M., Asunción" is credible. "-- Happy Patient" is not.

---

### Section 4: Trust Badges / Certifications

Display credentials in a scannable grid:

```
+---------------------------------------------------+
|  [COP Logo]  [MSPBS]   [University] [Courses]    |
|  Círculo     Ministerio  UAA         Latest       |
|  Odontológ.  Salud       2005        Training     |
|  Paraguayo   Pública                            |
+---------------------------------------------------+
```

**What to include:**
- COP membership (Círculo Odontológico Paraguayo)
- MSPBS Habilitación (if obtained)
- University degree + year
- Recent continuing education (last 2-3 years, not all history)
- Language badges: "Español | English" (bilingual credential)

**Avoid:** Listing every course taken since 2005. Pick 3-5 relevant recent ones.

### Section 5: "What I Won't Do" (Anti-overtreatment commitment)

This section is unique and differentiative. It explicitly states what she refuses to do:

```
+---------------------------------------------------+
|  WHAT I WON'T DO                                  |
|                                                   |
|  X  Recommend a crown when a filling suffices      |
|  X  Start treatment without a clear plan          |
|  X  Rush a patient into a decision                |
|  X  Treat a tooth that can be saved              |
|  X  Keep treatment going when it's not working    |
|                                                   |
|  "The best dentistry is the least dentistry needed|
|   to solve the problem."                          |
|                          -- Dra. GP              |
+---------------------------------------------------+
```

**Why this works:** It names the specific harms patients fear (overtreatment, upselling, rushing) and explicitly disavows them. This is more credible than saying "we don't do overtreatment."
