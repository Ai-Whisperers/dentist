## CARRD.CO SETUP STEPS

### Step 1: Create Account
1. Go to carrd.co
2. Sign up with Google (fastest)
3. Start new site → "Blank template"

### Step 2: Add Custom Domain
1. Settings → Domains → Add domain
2. Enter: dra-gabriela.com.py (or your registered domain)
3. Update DNS at your registrar:
   - Add CNAME: www → proxy.carrd.co
   - Add A record: @ → 75.2.70.75
4. Wait 24-48h for DNS propagation

### Step 3: Design Settings
- Background color: #FAFAF8 (warm white)
- Accent color: #1A5F5A (deep teal)
- Font: Montserrat (headers) + Open Sans (body)
- Max content width: 800px

### Step 4: Build Each Section
Use Carrd's drag-and-drop editor:

**Section 1 — Hero:**
- Add Cover block → set background image
- Add Heading block → "Odontología con Criterio. No con prisa."
- Add Subheading block → philosophy text
- Add Button block → link to WhatsApp URL

**Section 2 — Philosophy:**
- Add 3x Text/Info blocks for pillars
- Add Quote block for the testimonial

**Section 3 — Contact:**
- Add Text blocks for contact info
- Add another Button block for WhatsApp

### Step 5: Publish
- Click "Publish"
- Site is live at carrd.co/dragp (until domain points to it)
